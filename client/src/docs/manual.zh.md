# 介绍

欢迎使用 **ASK**，Carraro Group 开发的智能助手。

**ASK** 运用先进的文档检索，为依托于组织知识库的问题提供快速、易懂的定制化回答。文档检索遵循隐私规定，仅访问用户所属群组所允许的文档。

用户可像与同事对话一样，以自然语言与 **ASK** 交流。

## 术语表

**LLM（大型语言模型）**：  
一种人工智能模型，能基于输入理解和生成类似人类的文本。LLM 通过海量文本数据训练，采用统计方法预测并生成连贯且符合上下文的回答。例如 GPT（生成式预训练变换器）模型即属于此类。

**Token（标记）**：  
语言模型处理的基本文本单位。Token 可代表单词、单词片段、标点，甚至空格，具体取决于语言和模型。例如，单词 “unbelievable” 可能被切分为 “un”、“believ” 和 “able”。Token 的数量通常决定 LLM 回答的计算花费和输出长度。

# 工作区

## ASK

工作区是发起新聊天和管理各类互动会话的主要枢纽。

### 聊天框

聊天框提供多重功能，优化聊天体验。主要功能如下所列（自左至右）：

- **模型选择器**：允许用户选择偏好的 LLM 聊天模型。每种模型性能与 token 限额各异。选中模型 token 用尽后，系统会自动切换至下一个可用模型。
- **模式**：提供以下聊天模式选项：
    - **聊天**：适合一般会话与问答。
    - **聚焦**：理想于以单一文档为中心的交互。
- **文档选择器**：允许筛选可访问文档。默认显示用户授权访问的全部文档。搜索功能可快速锁定任何文档或文件夹。
- **知识源**：可指定回答所需知识库：
    - **模型**：使用选定 LLM 的内置知识。
    - **文档**：结合所选文档内容。
    - **网络**：连网检索信息。

### 消息

用户提交消息后，内容会显示在聊天界面，并伴随操作按钮：

- **用户消息**：
    - **复制**：将用户消息复制到剪贴板。
    - **编辑**：可修改用户消息并继续会话。

- **助手消息**：生成答案过程中，显示加载动画并展示各操作步骤。完成后仅保留最终答案及如下操作按钮：
    - **信息**：展示会话详情，包括：
        - **问题**：用户输入。
        - **模式**：当前聊天模式。
        - **已用 token**：token 使用量（分输入/输出）。
        - **LLM 模型**：回答生成所用模型。
    - **反馈**：打开表单，向开发者提交反馈。
    - **复制**：复制助手回答至剪贴板。
    - **展开**：从当前位置重新生成答案。
    - **重新生成**：重新生成新的回答。

按回答内容，文献引用可能以 ID 方式展示。一般在句末显示，标识确切引用的知识源。引用会按类型（文档或网页）分组并支持交互查看。

## 聊天记录

聊天记录板块按照最后编辑时间顺序，呈现往期聊天会话。

- 可以创建一个新聊天并决定其名称。
- 搜索框可通过输入任何聊天名称片段，快速匹配定位所有相关聊天。
- 可通过回收站图标删除历史聊天。

## 文档

文档板块展示用户依据可见群组可访问的全部已上传文档（见 *设置 > 账户数据 > 群组*）。

- 搜索框便于通过输入文档名称片段迅速查找、筛选所有匹配文档。
- 点击文档可查看其 Markdown 渲染效果。

根据权限（见 *设置 > 账户数据 > 权限*），可获得如下增强功能：
- **上传公共**：允许上传至共享区域。可见性由分配群组决定。仅上传者或有权用户可删除共享文档。
- **上传私有**：仅本人可见、管理的文档上传。仅上传者本人可见和删除此类文档。
- **删除文档**：在目标文档旁点击回收站图标执行删除。

# 设置

设置允许用户个性化体验并管理账户信息。

## 主题

可自定义视觉风格，如在浅色深色主题间切换。

## 语言

界面语言选择。仅影响视觉展示，与应用功能无关。

## 账户数据

账户数据板块展示当前已登录账户的详细信息，包括：

- **邮箱**：已登录账户的邮箱地址。
- **姓名**：账户持有人姓名。
- **权限**：已获授权权限及状态。
- **群组**：可访问的可见群组及高亮当前所属。群组控制特定文档、文件夹及功能的可见性。
- **域**：账户所属域信息。
- **总 token 限额**：每日总 token 配额（详细见 *token 消耗 > 账户 token 用量*）。
- **总 token 重置周期**：token 配额重置间隔（参见 *token 消耗 > 账户 token 用量*）。
- **试用到期日**：账户试用到期时间，届时账号将失效。

## Token 消耗

Token 消耗展示账户使用限制及数据：

- **账户 token 用量**：每日 token 总限额。
- **模型 token 用量**：逐模型的使用限额与状态，包括：
	- **模型**：当前面向用户的模型名称。
	- **服务商**：LLM 提供方。
    - **token 重置周期**：模型 token 用量的重置间隔。
    - **下次重置**：下次模型用量重置时间。
    - **token 用量**：模型各自 token 当前消耗状况。
